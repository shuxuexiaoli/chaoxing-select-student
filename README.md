# chaoxing-select-student — 学习通课堂活动自动化

学习通（超星学习通）创建课堂活动的自动化操作指南与脚本集，面向日常课堂教学：**选人、签到、随堂练习、抢答、主题讨论**等活动，都可以用 Playwright 自动化完成，不必在课堂上手动点。

## 能做什么

- **选人**：随机选人、指定班级选人，含完整的登录 → 进课程 → 进班级 → 创建活动流程
- **签到**：创建签到活动，并支持定时自动签到
- **随堂练习 / 抢答**：一键创建课堂练习与抢答活动
- **主题讨论**：批量定时发送主题讨论，带进度跟踪，可按课表自动排期
- **作业创建**：课堂作业的自动化创建流程

## 仓库结构

```
chaoxing-select-student/
├── SKILL.md        # 技能说明：给 AI 助手用的完整操作流程
├── scripts/        # 可直接跑的自动化脚本（选人、签到、讨论、抢答、练习等）
├── templates/      # 批量讨论、选人等场景的脚本模板
└── references/     # 流程文档与参考实现（登录、弹窗处理、课表同步、定时任务等）
```

## 使用方式

本仓库是一份给 AI 助手加载的技能（skill）：把 `SKILL.md` 连同 `scripts/`、`references/` 一起提供给助手，它就能按文档流程操作学习通。脚本基于 Playwright，使用前需按 `references/` 中的说明准备好登录与浏览器环境。
