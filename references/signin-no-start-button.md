# 签到活动流程差异（2026-06-08验证）

## 关键发现

签到活动的创建流程与其他活动类型**根本不同**：

| 活动类型 | 流程 | 需要"立即开始"？ |
|---------|------|----------------|
| 选人 | 添加→选人→填写事由→立即开始 | ✅ 是 |
| 主题讨论 | 添加→主题讨论→填写话题→立即开始 | ✅ 是 |
| 抢答 | 添加→抢答→填写内容→立即开始 | ✅ 是 |
| 随堂练习 | 添加→随堂练习→填写题目→立即开始 | ✅ 是 |
| **签到** | 添加→签到→普通签到→**自动开始** | ❌ **否** |

## 签到流程详情

1. 点击 `.add-activate-icon`（添加活动）
2. 点击 `li.btnSignIn`（签到类型）
3. 选择"普通签到" — **点击后签到立即生效，页面跳转到结果页**

第3步后页面直接显示签到结果（已签/未签/签到率），没有任何配置界面。

## 旧脚本误报问题

旧脚本（如 `exam_class_activities.py`）尝试在第3步后查找"立即开始"按钮，找不到就报告失败。但实际上签到已创建成功。

**判断签到成功的方法**：检查页面是否包含"已签"、"未签"、"签到率"等文本。

## 对自动签到脚本的影响

`~/.hermes/scripts/auto_signin.py` 及各节次签到脚本（`signin_12.py` 等）如果使用了"点击立即开始"步骤，该步骤实际是无效的（按钮不存在），但不影响签到创建——因为签到在点击"普通签到"时已经自动开始了。脚本报告的"失败"实际上是误报。
