# 数学主题讨论话题生成模板（学生生活版）

## 用户偏好
- **格式**：一句话精简描述，不要冗长的问题背景描述
- **内容**：与学生日常生活相关，不要抽象的工程/金融场景
- **数量**：每天1个话题（5班同时发送），26天完成
- **脚本位置**：`~/.hermes/scripts/auto_discussion.py` + `D:\BaiduSyncdisk\龙虾文件\scripts\auto_discussion.py`
- **进度文件**：`D:\BaiduSyncdisk\龙虾文件\教学资料\discussion_progress.json`

## 话题设计原则
1. 每个知识点对应2个话题（共13个知识点×2=26个话题）
2. 话题场景必须是学生熟悉的：生活费、跑步、游戏、外卖、手机电量、咖啡因、兼职收入、校园设施等
3. 一句话包含：场景描述 + 数学函数 + 要求使用的积分方法

## 话题设计模板

设计新话题时，按以下结构：
```
[学生场景] + [数学函数表达式] + [请用XX积分法求XX]
```

**场景库**：
- 💰 生活费、兼职收入、网购花费
- 🏃 跑步、骑自行车、走路
- 🎮 游戏升级、刷短视频、追剧
- 🍔 外卖订单、食堂就餐
- 📱 手机电量、流量消耗、充电宝
- ☕ 咖啡因、奶茶
- 📚 期末复习、课堂笔记
- 🏫 校园设施（喷泉、小路、食堂、跑道、人工湖、图书馆、教室温度、校园网速）
